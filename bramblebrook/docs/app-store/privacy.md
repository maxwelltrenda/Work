# App Privacy answers (App Store Connect › App Privacy)

**Do you collect data?** Yes.
**Used for tracking?** No, nothing. No ads, no analytics SDKs, no third-party tracking.

Data collected, all **linked to the user** (it belongs to their account) and used only for **App Functionality**:

| Apple category | What it is in Bramblebrook |
|---|---|
| Contact Info › Name | The farmer name and username (not a real name, but say yes to be safe) |
| User Content › Other User Content | Chat messages, village posts, direct messages |
| User Content › Customer Support | Feedback and reports the player sends |
| Identifiers › User ID | The account id |
| Usage Data › Product Interaction | The last few taps attached to feedback |
| Diagnostics › Other Diagnostic Data | Device type, screen size and errors attached to feedback |
| Other Data | The farm save, profile card, follows, village membership, last time online |

Not collected: email, phone, address, location, contacts, photos, payment info, health, browsing history,
advertising data. Without an account nothing is collected unless the player sends feedback.
